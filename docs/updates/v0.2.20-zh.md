# Sub2API v0.2.20 二改版更新（2026-11-08）

合并正式版 v0.2.20（dab829a4e），将 VERSION 修正为 0.2.20。上游标签内 VERSION 仍是 0.2.19，不以该文件误判发行版本。

保留上游中转额度查询、账号自动刷新与失败快照、Gemini 项目 ID 恢复和手动重授权、Claude 转 Gemini 系统消息兼容。适配上游身份清理函数改名及增强，复用 NeutralizeSystemIdentity 并保留本地 NormalizeClaudeSystemText 接口。

本次包含 v0.2.18—v0.2.20 的请求内存预算、超时治理、模型与协议修复、细粒度管理员权限及默认关闭的管理 MCP。数据库迁移随程序启动执行；部署前保存数据库备份和迁移校验和。保留旧镜像用于回退。

本地未提交的 DeepSeek 监控迁移与测试原样保留并备份；延续上次升级约定，不将其意外编入本次程序或应用数据库。不上传部署数据、数据库归档、环境文件和密钥。

为避免小内存服务器编译影响在线服务，新增 Local Update Build 工作流：GitHub 托管执行器串行安装依赖、单独类型检查、少量 i18n/二改余额组件与身份兼容测试、Vite 打包和单并发 Go 编译，输出带源码提交及 SHA256 的制品。不运行全量测试。本机仅下载并校验制品、组装镜像、执行备份和必要的健康检查。
