# Sub2API v0.2.17 二改版中文更新说明

本次将上游正式版 `v0.2.17`（`060d01604`）合入本地二改分支，并将程序版本号更新为 `0.2.17`。

## 上游更新

- 支持 Gemini 4 Argon 及 low / medium / high 思考档位，补齐计费价格和模型能力信息。
- Gemini chat/messages 兼容入口支持思考配置和流式思考摘要；新增可配置的最小输出 token 数。
- 支持 OpenAI API Key 账号的 Web Search 模拟，恢复账号管理筛选项平铺展示。
- 修复易支付查单与支付确认、支付宝退款查询、退款待定期间的余额及订阅扣减、Stripe 支付参数传递等问题。
- 修复 Responses 缺少 `created_at`、多个 Codex 工作区导入相互覆盖、Composite 分组协议路由、Antigravity 工具图片和原生 Gemini 工具调用等兼容问题。
- 改进 Vertex 共享容量不足重试、已删除服务账号处理及 Gemini 首次 401 判定。

## 保留本地功能

- New-API / Sub2API 上游额度查询、账号创建与编辑中的上游协议配置。
- 账号管理按所选间隔串行刷新当前页上游额度，列表 304 时继续查询，手动刷新同步额度，失败保留最近成功快照。
- Gemini 授权后的项目 ID 恢复与手动重新授权。
- Claude 转 Gemini 的系统消息兼容处理，保留用户指令、工具说明和普通厂商引用。
- 本机 Docker 镜像源配置及既有部署覆盖配置。

## 升级注意

ChatGPT OAuth / SetupToken 订阅账号不再调度和展示 `gpt-5.5`。需要在账号模型映射中指定可用替代模型，或使用 API Key 账号承接。详见上游说明 `docs/OPENAI_GPT55_RETIREMENT.md`。

本次上游没有新增数据库迁移。原目录中尚未提交的 DeepSeek 迁移及测试已备份并保留，不随本次版本提交、构建或应用。

## 小内存构建

类型检查、Vite 打包、Go 测试、Go 编译和镜像组装串行执行。Go 使用单核、`-p 1` 和内存回收限制；Vitest 使用单 worker；Node 设置堆上限。构建进程由 systemd cgroup 设置硬内存上限并禁用 swap，每 5 秒监控主机可用内存和换页。

Vite 已关闭打包阶段的重复类型检查，单独完成类型检查；本机打包保留原压缩行为并串行压缩分块。

- 336 项前端回归通过；318 个 Vue 文件和 223 个 TypeScript 文件完成分批类型检查，路由、入口及 Vite 配置另行检查通过。
- 949 项后端顶层测试通过：856 项配置、平台、Antigravity、协议转换、支付提供方及迁移测试，以及 93 项额度、Gemini 授权、Claude 兼容、思考配置和 Responses 核心专项。未执行完整 Go 测试集。
- 前后端构建及镜像组装通过，已部署镜像 `sub2api:0.2.17-local-1bee556b6`，源提交 `1bee556b6`。
- 新容器健康，重启数为 0，无 OOM；已认证版本接口返回 `0.2.17`，7 个前端资源（含账号页面）与构建产物逐字节一致。
