# Sub2API v0.2.25 二改版更新（2026-11-25）

合并上游 v0.2.21—v0.2.25（上游 `main` 0f6671457，标签 `v0.2.25`），并将
`backend/cmd/server/VERSION` 设为 `0.2.25`。

## 上游主要变化

- 账号管理：上游分组名称/备注自动同步、请求头覆写支持身份上报变量、身份上报变量审计修复。
- OpenAI：支持 GPT-6.2 Sol / Astra，改进 passthrough 400/错误透传与容量降载分类，compact 缓存 TTL 与 5m 缓存写入策略。
- 分组与计费：分组可强制 OpenAI Ultra Fast/Fast 档位，新增 Ultra Fast 定价与分组用量非阻塞 rollup。
- Gemini/Vertex：Gemini 4 Hydrogen 计费、Vertex 多区域端点与按区域加价、缓存与配额端点修复。
- 搜索：新增 Exa web search 模拟与 web_search sources 回传。
- 运维与安全：升级 gorilla/websocket 修复 GO-2026-6278，新增迁移 249—252（用量索引、OpenAI cache write TTL、分组 Ultra Fast 字段与定价）。
- 连接层：上游 TCP keepalive / TCP_USER_TIMEOUT 治理，降低死连接挂起。

## 本地二改保留

- 上游中转站余额查询、账号保存后自动探测、失败保留上次成功快照。
- Gemini OAuth 项目 ID 恢复与手动重授权。
- Claude 转 Gemini 系统消息兼容与身份清理适配。
- 账号列表/创建/编辑界面的上游中转站声明与余额单元格。
- 本地未提交的 DeepSeek 监控迁移与测试继续原样保留，不编入程序、不应用数据库。

## 新增本地功能：上游请求体 gzip

- 在共享 `HTTPUpstream` 出口对 `application/json`（含 `+json`）请求体做 gzip。
- 默认阈值 **256KiB**，以下不压缩；本地/私有主机、官方厂商端点和已带 `Content-Encoding`/摘要的请求跳过。
- 上游返回 400/415 且疑似不支持请求压缩时，自动回退为未压缩并记住该主机 1 小时。
- 目标：降低长上下文 Codex 每轮约 14MB 的“本站→上游”二次上传耗时（3Mbps 出口下约 40 秒）。
