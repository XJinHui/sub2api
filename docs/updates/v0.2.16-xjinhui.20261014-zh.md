# Sub2API v0.2.16 二改版中文版本说明

发布日期：2026 年 10 月 14 日。版本标签：`v0.2.16-xjinhui.20261014`。

本版基于上游 v0.2.16，修复账号管理自动刷新无法同步上游额度的问题，并保留上游中转站余额查询、Gemini 授权恢复和 Claude 到 Gemini 的兼容处理。

## 上游额度自动刷新

- 账号管理开启自动刷新后，按所选间隔逐个查询当前页的 Sub2API / New-API 上游账号额度。
- 账号列表返回 304、列表内容没有变化时，仍会查询上游最新额度。
- 顶部手动刷新按钮同时更新上游额度，无需逐个点击账号行的查询按钮。
- 查询失败时保留最近成功的额度和更新时间，显示失败原因；后续查询成功后清除旧错误。
- 新额度快照替换单元格内旧的手动查询结果，避免页面持续显示旧额度。
- 查询串行执行，避免重叠轮次；页面进入后台、关闭自动刷新或打开弹窗后暂停，离开页面取消请求。

使用方式：刷新账号管理页面，在已配置上游协议的 API Key 账号所在页面开启自动刷新即可。自动查询范围为当前页。

## v0.2.16 升级与兼容修复

- 同步上游 v0.2.16，包含 Gemini 显式上下文缓存、Haiku 5.5、Vertex API Key 支持、分组多语言及模型级临时冷却等更新。
- 保留 New-API / Sub2API 上游中转站额度查询，以及账号创建、编辑中的上游协议配置。
- 保留 Gemini 授权项目 ID 恢复和手动重新授权。
- 修复 Claude 请求转发至 Gemini 时的系统消息兼容问题，规范化开头身份信息并移除客户端计费元数据，保留用户指令、工具描述和普通厂商引用。
